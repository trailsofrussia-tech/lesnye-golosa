# Лесные голоса

Статическая версия аудиопульта для публикации через GitHub Pages.

Состав:

- `index.html` — интерфейс и вся логика приложения;
- `audio/` — 17 аудиофайлов;
- `.nojekyll` — отключает обработку Jekyll.

Для локальной проверки откройте папку через любой статический веб-сервер. После публикации GitHub Pages приложение работает без сервера и без входа посетителей в аккаунт.
